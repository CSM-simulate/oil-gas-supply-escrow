## Соответствие требованиям

| Требование исходного задания | Реализация |
|---|---|
| Solidity ^0.8.x, Hardhat или Foundry | Solidity ^0.8.28, Hardhat |
| OpenZeppelin ReentrancyGuard и управление доступом | ReentrancyGuard + AccessControl |
| buyer, supplier; все поля Batch; пять статусов | OilGasEscrow.sol |
| createBatch, fundBatch, markDelivered, releasePayment, refund | Реализованы с проверками ролей и состояния |
| Геттеры и пять обязательных событий | Реализованы; дополнительное событие отклонения |
| Отклонение партии из общего сценария | rejectBatch с reasonHash и немедленным возвратом |
| CEI, защита денежных функций, инварианты | Реализация и adversarial-тесты |
| Контракт и NatSpec | contracts/OilGasEscrow.sol |
| Тесты и скрипты деплоя | test/, scripts/ |
| README с инструкциями | README.md |
| GPT на этапах спецификации, кода, тестов, аудита, документации | prompt-log.md, результаты всех пяти этапов |
| Краткий prompt-log и запись ошибок GPT | prompt-log.md, воспроизведённая ошибка дедлайна |

| Вывод тестов | run-artifacts/tests.log |
| Git-репозиторий | Локальная история включена в комплект; main загружена в GitHub |

Единицы объёма, трактовка границы срока и подтверждение покупателем явно определены в `specification.md`. По заданной сигнатуре метаданные фиксирует buyer при создании после согласования с supplier; отдельное редактирование поставщиком не добавлялось, чтобы условия не менялись после оплаты.
